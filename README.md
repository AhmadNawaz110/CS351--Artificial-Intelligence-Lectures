## Course Introduction

Artificial Intelligence is tailored toward the design and application of machine intelligence in applied problem solving through knowledge representation and problem-solving techniques.

The course builds upon fundamental AI concepts and knowledge representation to study the representation, development, and application of intelligent algorithms in computing and robotics, including:

- Decision making  
- Automated learning  
- Data analysis  
- Intelligent systems design  

---

## Course Contents

This course covers:

- Knowledge representation and decision-making  
- Data types, algorithms, heuristics  
- Search space problems  
- Best First Search, Uniform Cost Search, A / A* algorithms  
- Shortest path finding  
- Adversarial search and Minimax tree searching  

### Supervised Learning

- Linear Regression  
- Logistic Regression  
- Random Forests  
- Decision Trees  
- Support Vector Machines (SVMs)  
- Artificial Neural Networks (ANNs)  
- Convolutional Neural Networks (CNNs)  
- k-Nearest Neighbors (KNN)  

### Unsupervised Learning

- k-Means Clustering  
- Hierarchical Clustering  
- Cluster analysis  
- Similarity metrics  

### Reinforcement Learning

- Agent-based learning  
- Reward optimization  

### Cybersecurity Applications

- Data preparation for ML  
- Anomaly detection  
- Injection attack detection  
- Adversarial learning

# Weekly Breakdown

## Week 1 – Introduction to AI & Agents

- Introduction to AI  
- Thinking & Acting: Humanly vs Rationally  
- Optimization Problems  
- Intelligent Agents: Simple & Model-Based Reflex Agents  

## Week 2 – Advanced Intelligent Agents & Search Basics

- Goal-Based & Utility-Based Agents  
- Learning Agents  
- State Space Search – I  

## Week 3 – Search Strategies I

- State Space Search – II (Examples)  
- Uninformed Search  
  - Breadth-First Search  
  - Depth-First Search  
  - Uniform Cost Search  

## Week 4 – Search Strategies II

- Informed Search & Heuristics  
- A* Algorithm  
- Best-First Search  

## Week 5 – Constraint Satisfaction Problems (CSPs)

- Defining CSPs  
- Backtracking Search  
- Constraint Propagation  
  - Forward Checking  
  - Arc Consistency  
- Applications in AI & Cybersecurity  

## Week 6 – Introduction to Machine Learning

- What is Machine Learning?  
- Categories: Supervised, Unsupervised, Reinforcement  
- Data Preparation & Feature Engineering  
- Training, Validation & Testing Splits  
- Cybersecurity-Oriented Datasets  

## Week 7 – Supervised Learning I — Regression

- Linear Regression  
- Logistic Regression  
- ROC Curve & Log-Loss  
- Application: Anomaly Detection  

## Week 8 – Supervised Learning II — Trees & Ensembles

- Decision Trees (Entropy, Gini Index, ID3/CART)  
- Overfitting & Pruning  
- Random Forests (Bagging, Feature Importance)  
- Application: Attack Detection  

## Week 9 – Supervised Learning III — Support Vector Machines (SVMs)

- Maximum Margin Classifier  
- Kernel Trick  
- Hyperparameter Tuning (C, Gamma)  
- Case Study: Intrusion Detection  

## Week 10 – Supervised Learning IV — Neural Networks

- Artificial Neural Networks (ANNs)  
- Backpropagation & Activation Functions  
- Introduction to Deep Learning  
- Cybersecurity Use Case: Phishing/Malware Detection  

## Week 11 – Supervised Learning V — Convolutional Neural Networks (CNNs)

- Convolution, Pooling, Fully Connected Layers  
- CNNs for Image & Sequence Data  
- Case Study: Packet Pattern Recognition  

## Week 12 – Supervised Learning VI — KNN & Model Evaluation

- k-Nearest Neighbors (Distance Metrics, Scaling)  
- Evaluation Metrics  
  - Precision  
  - Recall  
  - F1 Score  
  - ROC-AUC  
- Cross-Validation  
- Comparative Analysis: SVM vs ANN vs KNN  

## Week 13 – Unsupervised Learning I — Clustering

- Introduction to Clustering  
- k-Means & Variants  
- Similarity Metrics  
  - Euclidean  
  - Cosine  
  - Jaccard  
- Application: Log Analysis & Anomaly Detection  

## Week 14 – Unsupervised Learning II — Advanced Clustering

- Hierarchical Clustering & Dendrograms  
- Density-Based Methods (DBSCAN, OPTICS Overview)  
- Cluster Visualization (t-SNE, PCA)  
- Application: Malicious vs Benign Traffic Grouping  

## Week 15 – Reinforcement Learning & Cybersecurity Applications

- Reinforcement Learning Basics  
  - Agent  
  - Environment  
  - Reward  
- Q-Learning  
- Exploration vs Exploitation  
- Deep Q-Networks (DQN)  
- Adversarial Learning  
- Applications: Automated Defense Systems & Intrusion Response  
- Course Recap & Final Project Presentations
